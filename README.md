# 灵魂绑定 SoulBind 1.0.0

SoulBind 为物品记录绑定者，提供死亡保护、个人仓库和上线召回。适用于 Minecraft Java / Spigot 26.2、Java 25+；经济功能使用 Vault。

## 安装

1. 安装 **Vault** 和一个提供 Vault Economy 服务的经济插件，例如 EssentialsX。Vault 本身不负责产生经济账户。
2. 将 `dist/SoulBind-1.0.0.jar` 放入服务器 `plugins` 目录，然后启动服务器。
3. 插件生成 `plugins/SoulBind/config.yml`、`lang.yml`、`bindings.yml`。语言和价格修改后执行 `/soulbind reload`。

## 玩家用法

| 命令 | 功能 |
| --- | --- |
| `/soulbind` 或 `/灵魂绑定` | 打开中文绑定菜单 |
| `/soulbind settings` | 打开个人绑定模式 |
| `/soulbind vault` | 打开个人绑定仓库 |
| `/soulbind admin` | 管理员免费强制解绑入口 |
| `/soulbind reload` | 重载价格、语言与新玩家默认模式 |

在主菜单中点击下方背包物品，提交一件物品的预览；再点“绑定”或“解绑”确认。关闭菜单不会拿走物品。每次操作 **1 件**，绑定后单独占格，原堆叠中其他物品保持原状。若从堆叠绑定，请先留一个背包空格。

普通玩家只能解绑自己的绑定物品。绑定后新增 Lore `灵魂绑定 · 绑定者：玩家名`，原名称、附魔、原 Lore 和其他插件数据会保留；解绑只移除本插件的标记。归属使用 UUID，玩家改名不影响所有权。语言重载后，已有物品的绑定 Lore 会在后续检查、交互或上线时更新。

## 死亡、返还与销毁

- 背包、盔甲栏、副手及光标中的绑定物品死亡时不掉落，先安全存入绑定仓库，复活后自动发回；背包放不下的部分继续暂存。已开启 `keepInventory` 时不额外复制。
- 如果允许他人拾取，持有者死亡时物品回到**绑定者**，不会掉落。
- 开启“上线自动返还”后，每次上线召回未被销毁、但不在自己背包/光标中的绑定物品，包括普通箱子、末影箱、他人背包及地面掉落物。背包满时进入仓库。
- **绑定不是无敌。** 允许丢弃后，掉落物仍可被火、岩浆、爆炸、虚空或自然消失销毁；工具耗尽耐久、食物消耗、方块放置等正常消耗也不会被召回恢复。下界合金等物品仍保持其原本的原版抗性。
- 每件物品有唯一编号和版本。召回后旧位置的物品会失效；未加载区块或离线玩家中的旧版本，在后续加载、交互或检查时清除，避免重复领取。无需额外加载所有区块。
- 仓库有分页，点击物品领取。暂存数据随服务端重启保留。

为保留归属标记并防止加工生成副本，绑定期间禁止放入潜影盒、收纳袋，以及参与合成、熔炼、砂轮、锻造等转换加工；也不能通过发射器使用，或作为弓/弩弹药。需要上述操作时先解绑。**普通附魔及铁砧第一个槽位的修理、改名可用**；铁砧材料不能是绑定物品，放入时请手动拖放。普通箱子、末影箱可存放。漏斗不能从地面吸走绑定物品。

## 自定义价格与语言

`config.yml` 中两个价格独立，支持非负数，设为 `0` 表示免费：

```yaml
prices:
  bind: 1000.0
  unbind: 1000.0
defaults:
  allow-drop: false
  auto-return: true
  allow-others-pickup: false
maintenance-ticks: 100
```

`defaults` 只影响尚未设置过模式的玩家；已保存的个人模式继续生效。维护间隔至少 20 tick，修改后重启生效。

`lang.yml` 可修改菜单标题、按钮名称、说明、提示和绑定 Lore，支持 `&` 颜色码。请保留 `{owner}`、`{price}`、`{count}`、`{page}` 等占位符；绑定 Lore 必须包含 `{owner}`。缺少的语言键使用内置默认值。语法或价格无效时重载会失败，并继续使用之前的配置。

## 权限

| 权限 | 默认 | 功能 |
| --- | --- | --- |
| `soulbind.use` | 所有玩家 | 绑定、解绑、设置、个人仓库 |
| `soulbind.admin` | OP | 可见且可使用管理入口；免费强制解绑背包中任何人的物品；无视他人拾取限制 |
| `soulbind.reload` | OP | 重载配置；管理员权限也可重载 |

管理员强制解绑时仍需先将目标物品拿在自己的背包中，再提交到管理菜单。管理入口不会向无管理权限的玩家显示，操作时还会再次校验权限。

## 数据与构建

`bindings.yml` 保存归属、个人模式、物品快照、仓库及已销毁记录，采用临时文件加原子替换保存。运行时请勿手工编辑或单独删除此文件。备份时应同时备份插件数据、玩家数据和世界数据。

需要 Java 25 和 Maven。运行 `./build.ps1`，JAR 位于 `dist/`。脚本从 `JAVA_HOME` 和 `PATH` 查找已有工具；依赖缓存与临时文件默认放在 F 盘，可用 `-JdkHome`、`-MavenHome`、`-Repository`、`-TempRoot` 指定位置。

本插件只管理自己创建的绑定标记，不会自动接管其他绑定插件的物品。
